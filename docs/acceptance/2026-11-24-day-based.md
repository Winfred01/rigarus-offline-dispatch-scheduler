## Delivered boundary

- Slotless FullDay Draft and explicit positive ConfirmedRemainingDays contracts;
  no half-day estimates/history deduction or 0.5-day conversion.
- Additive schema13 with independent daily identity namespace, revision/member
  history and SQL uniqueness/cross-model triggers. Legacy records are unchanged.
- Daily Store create/edit/cancel/read/list/history with explicit nullable/empty
  workers; no Home Crew attendance or actual resources inferred.
- Strict separate HTTP contracts. **Daily writes default closed in the shipped
  sidecar**; explicit test opt-in exercises the implementation. Legacy UI/API is
  a protected compatibility path in slice1, not the final day business workflow.
- Read-only Needs Review report with original IDs/halves, owner/change context,
  known closures/unavailability/driver blocks and incomplete resource evidence.
- Verified pre-upgrade backup/rollback/retry; legacy snapshots reject daily
  records rather than ignoring their occupancy. Previous affected inputs Stale.
